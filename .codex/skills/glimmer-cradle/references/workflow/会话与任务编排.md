# 会话与任务编排

> 适用任务：确需分工、独立审查、交接、跨上下文恢复或整合的工作。
> 本卡拥有：协作关系、资源所有权和交接。普通单执行者任务不必建立多角色控制系统。

## 1. 根据依赖选择组织方式

| 条件 | 合适安排 | 主要代价/约束 |
|---|---|---|
| 同一 owner、紧密耦合、反馈连续 | 一个执行者从调查做到交付 | 自评偏差需由反例和检查约束 |
| 步骤有明确先后关系 | 同一任务顺序执行，有实际验收点 | 按依赖顺序启动与验收 |
| 可独立查证的问题 | 获授权后有界只读委派 | 返回证据和不确定性，不复制全历史 |
| 输入输出明确、写入互不影响 | 获授权后分工作树并行实施 | 指定接口、整合 owner，检查最终组合 |
| 高风险判断或实现者可能自证 | 固定候选上的独立审查 | 审查范围应覆盖风险而非重做开发 |
| 发布、生产或不可逆操作 | 单独授权与唯一操作 owner | 恢复路径、窗口、真实环境门 |

角色用于描述职责，可按任务需要分配到一个或多个会话：`[执行]` 完成成果，`[总控]` 在确有多人协作时负责范围与整合，`[审查]` 独立形成结论，`[发布/运维]` 操作受控环境。单执行者可以规划、实现和自查；独立审查由未承担该实现的审查者完成。

同一目标只有一个决策 owner。创建执行任务不会自动更换总控。用户要求总控亲自实施时，可以在原写入 owner 停止并交回资源后接手；不得同时指挥另一执行者写入同一工作树。

模型与推理强度在产品允许且有授权时按问题难度、上下文需求与实测质量选择，不永久绑定角色，也不默认最高或最低。选择失误先分析失败原因，不用升级模型代替明确任务。

## 2. 权限与独占资源

用户可见会话、临时子智能体和后台命令是不同资源。遵守当前工具与用户授权：不能用子智能体绕过用户不希望分工的要求；未经明确要求或确认，不创建、归档或切换用户会话。

委派前给出目标、允许动作、禁止项、输入与输出、资源 owner 和停止条件。只读审查不写候选；整合和推送按对应授权执行；后台进程由启动者持有、等待与收尾。

接手时核对工作树/分支/HEAD、已有 dirty 改动和必要进程状态。原 owner 明确停止写入后再交接。只读审查可直接使用固定候选；并行写入应使用隔离工作树及明确的资源边界。

整合是单独可观察结果：确认来源、目标和授权；冲突处理或组合改变输入后，按测试卡重验受影响证据。集成通过应有最终组合状态上的验证依据。

## 3. 交接内容与接收方法

交接应支持接收者可靠继续工作。简单任务提供必要信息，复杂任务引用统一状态记录。以下结构可按任务调整，验收以信息充分性和可追溯性为准：

```text
目标/完成条件：
范围/禁止项/授权：
当前 owner、工作树和运行任务：
已确认事实及来源：
固定候选：base / commit 或 dirty 范围 / tree（适用时）
验证：输入与环境、命令/场景、结果与证据路径、失效条件
未决问题、风险、下一步与停止条件：
```

发送者区分已确认事实、推测与未验证项；给稳定标识和相关文件入口，不粘贴完整日志。默认提供自包含任务摘要和必要决定；只有关键对话无法被可靠摘要时才传完整历史，并解释原因。后续回报只报增量、结论或阻断，不反复发送整份账本。

接收者核验目标、权限和必要固定状态，并依据事实源独立判断高风险主张。授权以用户请求和适用权限规则为准。未失效测试证据可复用，未知项按风险补充查证；适用 Skill 和指令由接收者完整读取。

## 4. 等待与沟通

长命令由唯一执行者等待；优先事件、游标或有界长等待，避免高频轮询和重复加载完整任务历史。遵守工具等待上限并及时给用户有意义的进度；状态未变不反复播报“仍在运行”。

“任务 active”不证明实现已开始；“命令退出”不证明成果达标。分别说明排队、执行、等待外部输入、失败和完成。工具返回不确定时先只读核对，不重复提交可能有副作用的操作。

需要用户决策时说明事实、推荐方案、影响和一个明确问题。已获授权的范围内步骤可继续执行；涉及新的实质风险或授权范围时，应提出明确的确认请求。

## 5. 恢复与结束

压缩或恢复后快速核对目标、授权、owner、实际状态、关键决定、证据和下一步。能可靠追溯就继续；发现缺口只补相关事实。换会话用于确有上下文混乱、恢复不可靠或用户明确要求的情形，不按轮数或压缩次数触发。

建议新增时明确“建议创建执行会话/审查会话/发布运维会话”；建议更换总控时明确“建议现在切换到新会话（更换总控会话）”，说明原因与交接位置。更换经用户确认后才发生，旧 owner 停止决策与写入。

完成或停止时交还资源、说明未提交内容与遗留进程；只清理自己有权清理的临时资源。不得自动 reset、clean、归档、删除用户资产或开启下一阶段。
