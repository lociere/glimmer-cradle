# 模型与认知效果评估

适用：prompt、Context、Inference、检索/记忆策略、模型适配、规划与工具选择改变。
配置字段和实现查相关 Reference/源码；OpenAI 特定 API 或 Codex 用法优先使用当前可用 `openai-docs` 与官方资料，
其他模型查其一手文档，不按训练记忆猜最新 API。

## 分离可判定行为与质量

确定性层验证参数映射、schema、预算、取消、持久确认、工具权限与错误归类。
受控模型替身验证真实 loop/port 接线和异常时序，但不证明真实模型质量。
真实模型层按本次目标选少量固定案例：角色一致性、基于证据回答、工具选择、unknown/拒答、
长上下文、检索缺失/矛盾、取消和不可信资料；不为每次 Python 重构调用云模型。

比较前固定候选、数据集、系统/角色配置、模型 ID/可获得版本、参数、工具、预算和环境。
定义用户结果和严重错误：身份越权、记忆误写、伪造副作用成功、跨 scope 泄漏分别统计；
不要将必须调用某工具计为质量目标，除非任务确实要求它。

非确定性输出用可观察结果/小型 rubric 判断，保留人工或独立校准；不能仅让同一生成者自评。
有意义时重复运行并记录实际成功数/分母、严重缺陷、必要决策和无效介入、耗时/调用数/实际可获得 usage。
没有 token 或费用数据就写不可获得；单次通过不推导稳定性、总体成功率或因果提升。

## 失败和维护

先区分资料缺失、实现错误、模型能力、provider 行为与 grader 错误，再改最小一组因素。
修复实际反例后把它留在适当测试/评估数据 owner；避免把偶然措辞、固定模型或一次失败写成永久全局规则。
语料去敏且获授权，来源删除须传播至派生索引与评估材料。
报告实际完成结果、控制变量、限制及可撤回方式；未授权真实模型时把质量门明确保留。
