# 操作指南

要完成一项已知工作时直接选择下表。首次学习用[受控教程](../tutorials/首次受控验证.md)，
查询精确规则用[技术参考](../reference/README.md)，查 owner 用[实现地图](../architecture/implementation/README.md)。
指南包含前置条件、实际步骤、反馈、失败与恢复；无需先打开 Skill 再返回同一指南。

| 任务 | 指南 |
|---|---|
| 准备工具、依赖和运行环境 | [本地开发环境](本地开发环境.md) |
| 从需求/验收、领域概念走到可运行改动 | [功能开发与缺陷修复](功能开发与缺陷修复.md) |
| 改 Service、Schema、IPC 或公开兼容 | [Schema 与跨进程契约变更](Schema与跨进程契约变更.md) |
| 改职责、依赖、资源或数据所有权 | [架构性改动](架构性改动.md)；已授权 v2 任务用[执行架构切片](执行架构切片.md) |
| 设计/实现 Web 或 Renderer、使用组件与浏览器工具、验收 UI | [前端开发与 UI 验收](前端开发与UI验收.md) |
| 修改具体运行组件 | [Kernel](Kernel开发.md)、[Cognition](Cognition开发.md)、[桌面与 Avatar](桌面与Avatar开发.md)、[音频](音频引擎开发.md)、[扩展](扩展开发.md) |
| 检查认证、权限、上传、IPC、网络或秘密边界 | [审查权限与外部边界](审查权限与外部边界.md) |
| 定位故障、性能或恢复数据 | [日志/Trace/DLQ](日志、Trace与DLQ排障.md)、[性能诊断](性能诊断.md)、[数据迁移与恢复](数据迁移与恢复.md) |
| 选择测试、证据复用、独立审查和接受条件 | [测试与验收](测试与验收.md) |
| 跨上下文接手、取消或结果未知 | [长任务与恢复](长任务与恢复.md) |
| 构建分发、安装、升级与回滚 | [客户端打包](客户端打包.md)、[Personal Server 部署](Personal%20Server部署.md)；共同事务语义查[工程参考](../reference/engineering-lifecycle.md) |
| 修改、迁移和验证资料 | [文档维护](文档维护.md)；命名规则在[命名参考](../reference/naming.md) |

开发准备、真实模型/设备启动、受控测试、安装和发布具有不同副作用。执行前核对实际 owner scripts；
教程的临时替身成果不授予生产、外部账号或发布操作权限。被替代指南仅在[历史](../history/README.md)保留原语境。
