## 2. 当前关键入口

| Owner | 当前入口链 | 构建输出 |
|---|---|---|
| Repository checks | root `package.json` façade → `@glimmer-cradle/repo-checks` | architecture/encoding 检查；不进入发布制品 |
| Workspace Supervisor | root `package.json` façade → `@glimmer-cradle/workspace-supervisor` → Product package owner entry | 开发期产品进程树、signal/exit 与故障域收口 |
| Kernel | `core/kernel/package.json` → `core/kernel/src/index.ts` → `core/kernel/src/main.ts` | `core/kernel/dist/index.js`，derived、未 tracked、基准未物化 |
| Cognition | `core/cognition/pyproject.toml` → `core/cognition/src/glimmer_cradle/cognition/host/process.py` | Python console entry，无独立 generated output |
| Desktop | `products/desktop/package.json` → source/build/package/verify | `products/desktop/dist/` 与 `dist/desktop/<version>/windows-x64/`，derived |
| Personal Server | `products/personal-server/package.json` → source/build/release/verify | `products/personal-server/dist/` 与 `dist/personal-server/<version>/linux-amd64/`，derived |
| Audio | `engines/audio/pyproject.toml` → `engines/audio/src/glimmer_cradle/audio/main.py` | Python console entry，无独立 generated output |
| Avatar | `core/avatar/GlimmerCradle.Avatar.Core.csproj` → local assembly → `hosts/unity-avatar-host/` | `build/components/avatar/{core,unity-host}/`，derived |
| Extension Host | `hosts/extension-host/package.json` → `hosts/extension-host/src/main.ts` | `hosts/extension-host/dist/main.js`，由 Kernel supervision fork |

## 3. 当前边界

- `contracts/` 是唯一 Contract Spine；`protocol/`、legacy generated projection、ZMQ/stdio RPC 与被替代的器官间手写 WebSocket 主线已删除。
- Extension Host 执行容器位于 `hosts/extension-host/` 独立 Node 子进程；Kernel 保留 supervision、权限、catalog、编排和 Projection owner。
- Kernel 物理根为 `domain/application/ports/adapters/runtime/composition`；Cognition 物理根为 `domain/application/ports/adapters/host`。
- Avatar Core 位于 `core/avatar/`，Unity/Cubism Host 位于 `hosts/unity-avatar-host/`；二者通过本地 assembly 单向依赖。
- Config/Extension/Product Document 的 serialized shape 由 `contracts/json-schema/` 拥有；normalizer、默认加载和 view mapping 留在直接 owner。
- Desktop installer 已有 Windows fixed-artifact 任务与 workflow，但 clean Windows
  installer/首启/升级/卸载、签名和公证仍未实机验证。
- `tools/` 只是 grouping root；两个叶子 workspace 均为 private、可测试且不被 runtime、deploy 或发布制品依赖。root `scripts/` 已删除。

主要迁移动作见 [物理拓扑差距与迁移地图](./11-物理拓扑差距与迁移地图.md)。
