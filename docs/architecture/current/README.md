## 更新一个当前事实

改动实际 owner、进程、依赖或运行语义时同步所属视图，并给源码/manifest 或真实证据依据。
描述已存在但未完整接入或未验收的能力时明确限制；目标、计划和历史经验不写成当前实现。
目录树集中维护于物理拓扑，短摘要允许提供必要背景，详细字段或流程不再复制。
