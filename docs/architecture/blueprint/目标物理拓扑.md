# 目标物理拓扑

> 范围：定义 Blueprint 完整落地后的实际目录、制品、安装和运行数据形态；不陈述当前完成度。
> 事实依据：架构蓝图、ADR-0013、ADR-0014、ADR-0015。
> 维护触发：owner、目录、入口、制品、安装投影或运行数据根发生设计变化时。

本页是理想完成态的唯一物理目录事实源。`<version>` 表示一次发布的具体版本目录，
如 `v0.2.0`；目录树中的其他名称均为最终路径，不是开放通配符。

## 5. 依赖方向与实施门

- Domain/Application 只依赖本 owner 的 Port；跨进程 DTO 只进入 Adapter。
- Desktop、Personal Server 等 Surface 只经 Kernel Surface Gateway 消费投影。
- Extension 第三方代码只在 `hosts/extension-host/` 崩溃域运行。
- 路径改变必须先更新本页、对应 ADR 与 Roadmap 完成态树，再实施。
- Current 与目标差距见 [物理拓扑差距与迁移地图](../current/11-物理拓扑差距与迁移地图.md)；
  实施顺序和删除门见 [M12](../../roadmap/manifests/M12-目标物理清单.md) 与
  [M13](../../roadmap/manifests/M13-目标物理清单.md)。
